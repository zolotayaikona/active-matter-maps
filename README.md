# Active Matter · Интерактивные карты (Discord Activity)

Discord-приложение (Activity, запускается прямо в голосовом/текстовом канале) с
интерактивными картами игры **Active Matter**. Карты приближаются, двигаются,
содержат точки интереса с подписями и фото, а в канале видно курсоры других игроков.

Официальные изображения карт и данные о точках взяты с
[Active Matter Wiki](https://active-matter.fandom.com/ru/wiki/Служебная:AllMaps)
(лицензия CC-BY-SA) и лежат локально в проекте.

---

## Возможности

- **Зум / панорама**: колесо мыши, пинч двумя пальцами, drag, двойной клик, кнопки `+`/`−`/`⤢`.
- **Точки интереса**: маркеры категорий (навигация, порталы, эвакуация, аномалии) с попапом —
  название, описание, фото, ссылка.
- **Слои**: включайте/выключайте категории маркеров.
- **Поиск**: находит точку по названию и мгновенно к ней перемещает камеру.
- **Карты**: 3 больших региона AMH (Остров Дальний, Штаб/Африка, Заброшенная Америка) плюс
  отдельные карты уровней **Порт, Щегольское, Озёрное, Дамба** — они нарезаны из изображения
  Дальнего и содержат полную разметку своего уровня. Пустые карты в списке не показываются.
- **Кнопки уровней**: выбор локации (Озёрное, Щегольское, Свалка, Военная база, Дамба,
  Грузовой порт, Завод, Догорск, Парк) фильтрует метки и **перелетает камерой** к этому участку;
  зоны и контуры зданий остаются видны (как на сайте-источнике).
- **Символы категорий** на карте при приближении, **тултип с названием** при наведении,
  попап с режимом, ссылками («Страница», «Видео», «Что можно найти») и кнопкой
  **«Скопировать ссылку»** на точку/вид.
- **Импорт с activematterhelp.ru**: 4 полных региона (Остров Дальний, Штаб/Африка,
  Заброшенная Америка, Бункер) с **~5600 точками интереса** и **380 подсвечиваемыми зонами**
  (POI-районы и области монстров), иконками и цветами по категориям.
- **Тоглы категорий**: выходы, спавны, двери и ключи, ценности, лут, документы, враги,
  опасности, квесты, головоломки, POI.
- **Фильтры** по локации (Свалка, Грузовой порт, Завод, Озёрное…) и по режиму рейда
  (Обычный, Заросли, Искажение, Кровавая бойня…).
- **Подсвечиваемые зоны**: полигоны POI (оранжевые) и монстров (красные) с подписями при зуме.
- **Обозначения зданий и районов**: 380 подписей зон (Электростанция, Ангар 84, Склад 1…) и
  13 названий локаций (Грузовой порт, Догорск, Завод, Парк…) прямо на карте.
- **Координаты под курсором** в системе координат оригинальной карты.
- **Мультиплеер**: список участников и живые курсоры других игроков канала (WebSocket).
- **Авторизация Discord**: имя и аватар игрока через Embedded App SDK.
- **Работает и без Discord** — как обычный веб-просмотрщик карт.

## Требования

- [Node.js](https://nodejs.org) 18+ (проверено на 24.x)
- Для запуска в Discord: [cloudflared](https://github.com/cloudflare/cloudflared) (или ngrok) для HTTPS-туннеля

## Быстрый старт (браузер, без Discord)

```powershell
npm install
npm start
```

Откройте <http://localhost:3001>. Приложение запустится в демо-режиме: карты, маркеры,
слои, поиск и присутствие (курсоры между вкладками браузера) работают. Разные «комнаты»
задаются параметром `?room=имя`.

## Запуск как Discord Activity

Перед запуском можно проверить готовность:

```powershell
npm run discord:check
```

Скрипт проверит `.env`, наличие SDK и данных и выведет оставшиеся шаги.

### 1. Создайте приложение

1. Откройте <https://discord.com/developers/applications> → **New Application**.
2. На странице **Installation** включите оба контекста установки:
   **User Install** и **Guild Install**.

### 2. OAuth2

1. Раздел **OAuth2** → **Redirects** добавьте `https://127.0.0.1` (заглушка, SDK сам
   возвращает пользователя в Activity) и сохраните.
2. Скопируйте **Client ID** и **Client Secret**.

### 3. Настройте переменные окружения

```powershell
Copy-Item .env.example .env
```

Заполните `.env`:

```
DISCORD_CLIENT_ID=ваш_client_id
DISCORD_CLIENT_SECRET=ваш_client_secret
PORT=3001
```

> `DISCORD_CLIENT_SECRET` — секрет. Никогда не коммитьте `.env` (он уже в `.gitignore`).

### 4. Запустите сервер и туннель

В первом терминале:

```powershell
npm start
```

Во втором терминале (порт должен совпадать с `PORT`, по умолчанию 3001):

```powershell
npm run tunnel
# или: cloudflared tunnel --url http://localhost:3001
```

cloudflared напечатает публичный URL вида `https://funky-jogging-bunny.trycloudflare.com`.

### 5. URL Mapping и включение Activity

1. В настройках приложения раздел **Activities → URL Mappings** добавьте строку:

   | PREFIX | TARGET |
   |---|---|
   | `/` | `funky-jogging-bunny.trycloudflare.com` |

   (указывайте хост без `https://`).
2. Раздел **Activities → Settings** → включите **Enable Activities**.

### 6. Запуск в Discord

Включите **Developer Mode** (User Settings → Advanced). Затем в любом канале
откройте **App Launcher** и запустите своё приложение. Activity откроется во
встроенном окне; при первом запуске Discord запросит авторизацию.

## Постоянный адрес (бесплатный хостинг)

cloudflared-туннель даёт HTTPS, но адрес меняется при каждом запуске. Чтобы получить
**постоянный** адрес без своего домена, приложение можно задеплоить на бесплатный
Node-хостинг. В проекте уже есть `Dockerfile`, `render.yaml` (Render.com) и `fly.toml` (Fly.io).

Адрес будет вида `https://active-matter-maps.onrender.com` — его и указывают в Discord
URL Mappings (`/` → `active-matter-maps.onrender.com`, без `https://`).

### Вариант A — Render.com (через GitHub)

1. Залей проект в свой GitHub-репозиторий.
2. На <https://render.com> → **New → Blueprint** → выбери репозиторий (Render прочитает
   `render.yaml`).
3. В настройках сервиса задай переменные окружения:
   `DISCORD_CLIENT_ID` и `DISCORD_CLIENT_SECRET` (значения из `.env`).
4. Deploy. Render соберёт Docker-образ и выдаст HTTPS-URL.
5. В Discord URL Mappings замени адрес туннеля на `*.onrender.com`.

> Free-план Render «засыпает» после ~15 минут простоя — первый запрос после паузы
> будет грузиться ~30–60 секунд. WebSocket (живые курсоры) поддерживается.

### Вариант B — Fly.io (без GitHub, через CLI)

```powershell
flyctl launch --no-deploy   # имя приложения и регион
flyctl secrets set DISCORD_CLIENT_ID=... DISCORD_CLIENT_SECRET=...
flyctl deploy
```

URL будет `https://<app>.fly.dev`.

## Как это устроено

```
server/index.js      Express: статика, /api/config, /api/token (обмен OAuth-кода),
                     WebSocket /ws (комнаты = instance ID канала) для live-курсоров
public/index.html    Разметка приложения
public/styles.css    Тёмная тема, адаптив, стили маркеров и попапов
public/app.js        Просмотрщик карт (pan/zoom), маркеры, слои, поиск, SDK, presence
public/data/maps.json Сгенерированные данные карт и маркеров
public/maps/*.webp   Официальные изображения карт
public/poi/*.webp    Фото точек интереса
vendor/...           @discord/embedded-app-sdk (отдаётся сервером из node_modules)
tools/convert-maps.mjs     Сборка maps.json из данных вики
tools/fetch-map-images.ps1 Загрузка картинок с вики (через curl)
tools/discord-check.mjs    Проверка .env/SDK/данных перед запуском в Discord
```

### Координаты маркеров

В вики-картах точка задаётся в системе `mapBounds` с `origin: bottom-left` и порядком
`xy`. Клиент переводит её в пиксели изображения:

```
left = x / boundsW * imageW
top  = imageH - y / boundsH * imageH
```

Поэтому данные не зависят от разрешения экрана.

## Работа с данными карт

### Импорт с activematterhelp.ru

Полный импорт интерактивных карт сообщества [activematterhelp.ru](https://activematterhelp.ru/maps):
скачивание тайлов, сборка их в цельные изображения и генерация данных (метки, зоны, категории,
фильтры).

```powershell
npm run import-amh          # скачать тайлы + собрать изображения + данные
npm run import-amh -- --no-tiles   # только пересобрать данные (изображения уже есть)
```

Результат: `public/maps/amh-*.webp` и `public/data/amh-maps.json`. Для уровней Дальнего
(порт, щегольское, озерное, дамба) дополнительно нарезаются отдельные карты `amh-loc-*.webp`
с переносом меток, зон и подписей этого уровня (зоны привязываются по центру к bounds уровня).
Исходные чанки сайта лежат в `data/amh/` (`data-markers.mjs`, `MapsTab.js`, `markerNaming.mjs`).
Скрипт `tools/import-amh.mjs` использует `sharp` для сборки тайлов и нарезки карт.

Координаты меток и зон переводятся из игровых в доли изображения по тем же границам CRS,
что и на сайте:

```
fx = (lng - leftTop.x) / (rightBottom.x - leftTop.x)
fy = (rightBottom.y - lat) / (rightBottom.y - leftTop.y)
```

### Данные Fandom-вики

Данные вики уже скачаны в `data/*_wikitext.txt`. Пересобрать `public/data/maps.json`:

```powershell
npm run convert
```

Обновить изображения из вики (нужен `curl.exe` — он входит в Windows 10+):

```powershell
npm run fetch-images
npm run convert
```

## Как добавить карту или точку

- **Новая карта**: положите изображение в `public/maps/`, добавьте запись в массив `MAPS`
  в `tools/convert-maps.mjs` (id, название, файл, source) и запустите `npm run convert`.
- **Новая точка**: добавьте объект в `markers` соответствующей карты в `maps.json`
  (`categoryId`, `x`, `y`, `title`, `description`, `link`, `image`).
- **Новая категория/слой**: добавьте объект в `categories` карты; клиент построит слой автоматически.
